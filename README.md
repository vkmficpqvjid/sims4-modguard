## Overview

ModGuard is a standalone utility for The Sims 4 that scans your Mods folder for conflicting tuning XML files, duplicate package hashes, and missing dependencies, then generates a prioritized conflict report with resolution suggestions. A visual load order editor lets you adjust mod priorities without manually renaming files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Sims 4 ModGuard** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Conflict Detection** | Scans for conflicting tuning XML definitions across all installed mods |
| **Duplicate Detection** | Identifies duplicate package hashes causing redundant mod loading |
| **Dependency Check** | Flags mods with unmet dependencies before launching the game |
| **Load Order Editor** | Visual priority editor for resolving conflicts without file renaming |
